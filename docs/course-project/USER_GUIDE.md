# 课程版 Agent Arena 用户手册

首次体验请先读 [逐步体验指南](EXPERIENCE_GUIDE.md)，其中包含只读浏览、MetaMask 测试账户导入、当前本地 RPC 及每一步的成功标志。本手册侧重通用角色与业务规则。033 已完成真实 LLM 与本地资金的 CLI 验收；034 MetaMask UI 验收仍等待扩展确认，尚未完成签名或发送新交易。下面是操作说明，不把脚本签名当作钱包界面验收。

## 环境与入口

前端主入口为 `/`（资金概览），导航包含 `/tournaments`（奖金赛事）、`/audit`（审计流水）、`/agents`（我的 Agent）、`/guide`（使用指南）。原黑客松的下注、PvE、钱包等入口跳转至课程页面。

当前真实模型入口为 `http://localhost:3002`，API 为 `http://localhost:18081`，本地 RPC 为 `http://127.0.0.1:18545`（31337）；登录消息核对 `localhost:3002`。033 后记录为 6 场、450 DUSD 赞助、200 奖金、250 退款、0 托管；#5 真实 LLM 蓝方已领奖，#6 已取消并退款。3001 / 18080 保留旧演示，不是本轮新比赛入口。

“使用指南”页面标题为“怎么开始？”，按角色给出第一步入口；完整钱包账户和金额演练见上方逐步体验指南。

连接 MetaMask / RainbowKit 支持的钱包，选择后端 `/api/config` 配置的网络：本地 Anvil（chain ID 31337）或 Sepolia（11155111）。本地环境还必须核对 RPC 端口：链 ID 相同不保证连接的是同一个节点。页面上方可展开“网络详情”，查看合约地址、确认数和索引进度；“链数据已同步”表示服务当前的同步状态，不代表某笔操作已成功。

课程代币为 DUSD，6 位小数，没有兑换承诺。报名费为零，两名参赛者争夺赞助奖金；没有观众投注。演示管理员提前分配 DUSD；钱包需要本网络的 ETH 支付网络费。后端不保存资金私钥。

报名、开赛、审核和到期状态读取链上最新区块时间，不以浏览器本地时钟判断截止；创建期限也以链时间为基准。详情页“奖金与规则”展示相关期限和当前链时间。没有有效部署配置时不能发送课程交易，不回退到历史合约地址。

## 中英文切换

顶部工具栏点击 **English** 切换为英文，点击 **中文** 切回中文。手机上按钮同样直接可见，不需要展开导航。首次默认中文；选择会保存在本浏览器，刷新、关闭再打开或访问其他页面后继续使用所选语言。浏览器禁止本地存储时，本次页面内仍可切换，刷新后可能恢复中文。

切换即时生效，保留当前表单输入和筛选条件，不触发钱包签名或资金交易。钱包连接弹窗也使用所选语言；MetaMask 扩展自身的界面由钱包设置控制。

## 钱包登录与角色

1. 点击顶部“连接钱包”。若网络不符，点击提示中的“切换到正确网络”，也可从顶部网络菜单或钱包手动切换。
2. 点击“签名登录”。前端从服务端取得随机 nonce 和原始消息，钱包签名后换取登录 token；消息不可修改，nonce 单次使用。登录签名不转账，也不收网络费。
3. 顶部显示“管理员”“主办方”“审核员”或“普通用户”。普通用户表示没有全局管理角色，不等于已经报名；本场实际身份在详情页“你的下一步”和“我的赛事账户”另行显示。
4. 切换钱包或网络会清除登录状态，需要重新签名。顶部地址菜单可以查看账户或断开连接；换演示身份时在 MetaMask 切换，并核对页面地址。

管理员在奖金赛事页面展开“管理员：管理主办方与审核员权限”，选择角色和目标钱包，点击“预览授予权限” / “预览撤销权限”，再确认签名。主办方创建、开赛、运行对战、提交结果或在开赛前取消；指定审核员审核结果和裁决异议；普通钱包可创建 Agent、报名、赞助和领取自身资金。指定审核员不能赞助自己审核的赛事。赛事主办方、指定审核员及两位参赛者的钱包不能互相冲突；权限最终由合约校验。

## 所有链上操作的共同确认步骤

1. 点击具体业务按钮，如“确认报名，查看费用”“开始比赛”或“领取 100 DUSD 奖金”。页面自动打开交易确认弹窗，先模拟并估算。
2. 核对“本次操作”及其中的金额、钱包、赛事信息，再查看“预估网络费”。ETH 网络费与业务中的 DUSD 金额不同。需要时展开“交易详情”核对目标合约、链 ID 和签名账户。
3. 点击大按钮“确认并在钱包签名”，再到钱包确认。首次点击业务按钮不会自动发送交易。
4. 等待“交易已确认成功”，点击“完成”。页面和已确认流水可能需要稍后刷新。

操作参数在估算时固定；修改表单后重新点击业务按钮并估算。网络费基于当时的链状态，实际费用以回执为准。

Escape 或“收起窗口”可以关闭弹窗，既不会重置交易，也不会取消已发交易。待处理时页面底部保留“查看交易进度”或“查看并检查回执”入口。签名、确认中或结果未明时不要重复提交；可点击“检查链上回执”核对最终状态。拒绝签名不会发送交易；执行回滚会显示原因，不能算作付款成功。

## Agent 定义与报名

1. 打开“我的 Agent”，在“创建参赛 Agent”填写名称，选择“进攻型”或“防守型”，也可填写“策略与性格”。点击“保存 Agent，准备参赛”。
2. 保存不需要链上交易。定义不可修改，后端持久化名称、策略、所有者与内容哈希；“查看定义指纹”展开哈希。策略变化请创建新的定义。平台统一配置模型，不收集个人模型 API key 或任意 API URL。
3. 在“已保存的 Agent”点“带它去参赛”，或从“奖金赛事”打开尚在报名期的赛事详情。
4. 在“参与这场赛事”选择“报名参赛”，选择自己创建的 Agent，点击“确认报名，查看费用”，按共同确认步骤签名。成功后看到报名人数和自己的 Agent。
5. 报名截止前可点击“退出本场报名”；交易确认后名额恢复，并可重新选择 Agent 报名。截止之后不能继续报名、赞助或退出。

历史 #1 使用确定性模拟，只识别 `aggressive` / `defensive` 等关键词；当前 3002 环境已配置真实 LLM，#5 留有 14 回合、28 次成功调用记录。“允许确定性模拟”或“已配置模型”都是服务配置，某场实际模式与调用是否成功须看“比赛回放”、调用统计和证据。

## 创建、赞助与开赛

1. 主办方在奖金赛事页点击“创建赛事”，展开后填写名称、指定审核员钱包、可选规则链接及期限；默认距报名截止 15 分钟、距最终结算期限 24 小时、审核窗口 60 秒。审核窗口为 60 秒至 30 天；最终期限须留出完整审核时间。点击“预览并创建赛事”，按弹窗核对并签名，赛事被确认、索引后出现在列表。“收起创建表单”只收起输入区域。
2. 赞助者在报名期打开详情“参与这场赛事”，选择“赞助奖金”，输入 DUSD 金额（最多 6 位小数）；也可选择 25 / 100 / 200 DUSD 快选金额。
3. 点击“1. 授权 100 DUSD”（金额随输入变化），确认并签名，等待授权成功。授权 spender 是配置中的 PrizeEscrow，不是 TournamentManager；授权本身不会扣款或增加奖池。
4. 显示授权充足后点击“2. 确认赞助”，再次确认并签名。赞助交易成功后，“本场奖金总额”和“我的赞助 · 仍在托管”增加，钱包可用余额减少。
5. 报名截止、人数为两位、奖金非零且剩余时间足够审核后，主办方在“你的下一步”点击“开始比赛”，按弹窗签名。满两人仍须等报名截止，不能提前开赛。

## 对战、证据与结果审核

1. 赛事处于对战中时，主办方点击“运行 Agent 对战”。这是后端任务，不需要再发送链上交易；后端持久化回合与证据，绝不代替钱包提交结果。真实请求或解析失败会中断比赛，不编造回合或赢家；查看错误后，仅在后台允许重试时可点“恢复对战执行”，历史失败和调用预算仍保留。已完成比赛不能重新运行。
2. “比赛回放”展示地图、HP、动作及实际运行模式。可以“播放回放”、暂停、切换上一/下一回合或拖动滑块；“跟随最新回合”恢复最新状态。“查看回合动作与决策记录”展开详细动作。
3. 主办方点击“查看比赛证据”，或到“比赛证据”点击“展开完整证据” / “下载证据 JSON”。浏览器核对 canonical JSON 的 Keccak-256 与返回的证据哈希、对战结果哈希，显示“内容校验通过”及“已查看”。
4. 对战完成、有冠军、证据一致且仍有完整审核时间时，主办方点击“提交比赛结果”，按弹窗签名提交冠军地址和证据哈希。平局不得编造冠军，等待到期取消及退款。
5. 结果提交后显示“审核窗口中”。参赛者或实际赞助者可在窗口内展开“对结果有异议？提交复核申请”，填写“异议依据”，点击“提交异议，查看费用”并签名。后端保存说明只是草稿；对应哈希出现在确认事件中，才表示链上异议已经生效。
6. 完整审核窗口结束后，指定审核员先查看证据。没有异议时点击“审核通过，确认冠军”。有异议时点“查看异议并裁决”，在“裁决结果”选择冠军或“否决结果，取消赛事并退款”，填写“裁决理由”，点击“提交裁决，查看费用”并签名。确认冠军需要已查看且匹配的证据；选择否决并取消退款不以原证据完整为前提，但仍需指定审核员权限、完整审核窗口结束及理由。最终期限到达后不允许审核结算。
7. 提交后证据区应显示“内容与链上记录一致”。哈希一致只证明内容承诺一致，审核员仍需判断规则和对战结果正确性。

## 领奖、取消与退款

- “已结算 · 待领奖”表示审核完成，但尚未付款。冠军连接自己的钱包，在“你的下一步”点击“领取 100 DUSD 奖金”（金额随本场奖金变化），签名成功后显示“已领奖”。只能领取一次。
- 开赛前主办方可展开“需要取消这场赛事？”，填写“取消原因”，点击“取消赛事，查看费用”并签名。审核员裁决否决结果也会取消赛事。
- 报名截止且人数不足，或到达最终结算期限时，任意钱包可点击“取消赛事，开启退款”。该路径不依赖管理角色继续有效。
- “已到期 · 待退款”不等于已取消，更不等于款项已经退回。先确认取消，再由各赞助者连接原出资钱包，点击“领取 200 DUSD 退款”等相应金额按钮。每位赞助者独立领取，不由后端或主办方批量转账。
- “已取消”只表示赛事取消，不表示所有赞助者均已退款。“我的赛事账户”可核对“我的待退赞助”“可领取退款”和“钱包可用余额”；以自己的余额增量和退款事件确认到账。

## 流水与问题处理

资金概览显示已确认赞助、已发奖金、已退赞助、待结算资金及索引进度。待结算资金为累计赞助减去奖金和退款。审计流水按赛事查询事件，可筛选当前页或“导出当前页 JSON”；搜索仅筛选本页，导出保留本页全部原始记录，并不是全库导出。Sepolia 交易提供 Etherscan 链接，本地网络显示交易编号。赛事选择器显示最新 100 场，每页 50 条事件。

遇到问题先检查顶部地址、钱包网络、签名登录状态和赛事“你的下一步”。服务连接失败可点“重新连接”，链数据暂未就绪可点“重新检查”，网络不匹配可点“切换到正确网络”。等待索引不代表需要重复交易；回执已成功但流水暂未更新时，稍后刷新并查看“网络详情”中的索引进度。

赛事状态按链时间区分报名中、等待开赛、审核窗口、待领奖和到期退款。若“当前链时间”尚未读取成功，先检查节点，不能用电脑时间假定期限已到。金额、状态和权限仍由合约最终校验；页面不会把尚未签名或未确认的操作当作成功。
