# 课程版 Agent Arena 用户手册

## 环境与入口

前端主入口为 `/`（资金概览），导航包含 `/tournaments`（赛事）、`/audit`（审计流水）、`/agents`（我的 Agent）、`/guide`（使用说明）。原黑客松的下注、PvE、钱包等入口跳转至课程页面。

连接 MetaMask / RainbowKit 支持的钱包，选择页面 `/api/config` 配置的网络：本地 Anvil（chain ID 31337）或 Sepolia（11155111）。每笔链上操作都由当前钱包签名。报名、开赛、审核和到期按钮读取链上最新区块时间，不以浏览器本地时钟判断截止；创建期限也以链时间为基准。没有有效部署配置时页面禁用链上写入，不回退到历史合约地址。

课程代币为 DUSD，6 位小数，没有兑换承诺。报名费为零，两名参赛者争夺赞助奖金；没有观众投注。演示管理员提前分配 DUSD；钱包需要本网络的 ETH 支付 gas。后端不保存资金私钥。

## 钱包登录与角色

1. 点击顶部“连接钱包”。若网络不符，点击部署提示中的“切换网络”。
2. 点击“签名登录”。前端从服务端取得随机 nonce 和原始消息，钱包签名后换取登录 token；消息不可修改，nonce 单次使用。
3. 顶部显示当前角色。切换钱包或网络会清除登录状态，需要重新签名。

管理员（admin）在赛事页面授予或撤销 organizer / auditor 角色。组织者创建、开赛、提交结果或在开赛前取消；指定审计员审核结果和裁决异议；普通钱包可创建 Agent、报名、赞助和领取自身资金；指定审计员不能赞助自己审核的赛事。权限最终由合约校验。赛事组织者、指定审计员及两位参赛者的钱包不能互相冲突。

## Agent 定义与报名

1. 打开“我的 Agent”，填写名称、策略与性格，保存定义。
2. 定义不可修改，后端持久化名称、策略、所有者与内容哈希；策略变化请创建新的定义。平台统一配置模型，不收集个人模型 API key 或任意 API URL。
3. 打开赛事详情，在报名截止前选择自己创建的 Agent。
4. 点击“估算报名”，在本页交易状态卡检查操作和 gas 估算，再点击“钱包签名发送”。确认成功后参赛地址和 Agent 哈希公开可见。
5. 报名截止前可按同一方式“估算退出报名”。

## 创建、赞助与开赛

1. 组织者在赛事页填写名称、审计员钱包、可选规则链接、报名截止时间、最终结算期限和审核窗口。审核窗口为 60 秒至 30 天；最终结算期限须留出完整审核时间。
2. 点击“模拟并估算创建费用”，查看 ETH 费用估算，在钱包签名发送。创建事件被确认、索引后赛事出现在列表中。
3. 赞助者在开放报名时输入 DUSD 金额（最多 6 位小数）。点击“1. 估算授权”，签名发送授权，等待回执成功。授权 spender 是配置中的 PrizeEscrow，不是 TournamentManager。
4. 再点击“2. 估算赞助”，签名发送赞助交易。授权本身不会增加奖池，赞助交易确认后奖池增加。
5. 报名截止、人数为两位且奖金非零后，赛事组织者点击“估算开赛”并签名发送。

## 对战、证据与结果审核

1. 赛事处于对战中时，组织者点击“运行 Agent 对战”。后端生成并持久化回合与证据，绝不代替钱包提交结果。任务中断后可恢复执行；已完成比赛不能重新运行。
2. 页面每 10 秒刷新数据，显示回合地图、HP、动作和推理文本。通过滑块回放；“跟随最新回合”恢复到最新状态。页面明确显示 `llm` 或 `deterministic_simulation` 模式。
3. 组织者下载或展开完整证据 JSON。浏览器核对原始 canonical JSON 的 Keccak-256 与返回的证据哈希、对战结果哈希是否一致。
4. 对战完成、有非空冠军且证据一致时，组织者点击“估算提交结果”，签名提交冠军地址与证据哈希。平局不得编造冠军，等待到期取消及退款。
5. 结果提交后开始完整审核窗口。参赛者或实际赞助者可在窗口内填写异议说明，点击“保存说明并估算异议”，再签名发送。后端保存说明只代表草稿；对应哈希出现在已确认事件中，才代表异议生效。
6. 审核窗口结束后，指定审计员先查看完整证据。没有异议时点击“估算审核通过”。存在异议时选择冠军或“否决结果、取消赛事并退款”，填写裁决说明，然后保存、估算并签名提交。最终期限到达后不允许审核结算。
7. 哈希一致只证明内容承诺一致，独立审计员仍需判断规则和对战结果正确性。

## 领奖、取消与退款

- 赛事已结算且当前钱包是冠军时，详情显示其可领取金额。点击领取按钮，估算并签名；奖金只能领取一次。
- 开赛前组织者可填写理由并取消比赛。审计员裁决否决结果也会取消。
- 报名截止后人数不足，或赛事超过最终结算期限时，任意钱包可点击“估算到期取消”。该过程不依赖管理角色继续有效。
- 已取消赛事的赞助者连接自己的钱包，在详情领取自身剩余可退赞助金额。每位赞助者独立领取，不由后端或组织者批量转账。

## 流水与错误处理

资金概览显示已确认赞助、已发奖金、已退赞助、待结算资金及索引进度。待结算资金为累计赞助减去奖金和退款。审计流水页选择赛事、分页查询事件，可筛选当前页或导出当前页 JSON；Sepolia 交易提供 Etherscan 链接，本地网络显示交易哈希。界面声明赛事选择器显示最新 100 场、每页 50 条事件。

交易状态卡展示模拟估算、等待钱包批准、等待链上确认、成功、错误和状态待确认。拒绝签名不会发送交易；模拟失败/回滚会显示原因。确认超时后暂锁新操作，点击“检查回执”确认最终状态，避免重复发送。Gas 显示 ETH，基于当前 gas price；实际费用以回执为准。索引存在确认延迟，回执成功后可能需要等待流水更新。

后端连接失败、部署未配置或网络不符时，会显示明确提示并禁用写入。金额、状态和权限仍由合约最终校验。页面不会声称尚未部署或未确认的操作已经成功。
