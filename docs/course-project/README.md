# Agent Arena 课程版文档导航

本轮重构开始于 2026-10-09。课程版定位：**AI 赛事奖金托管、结算与审计 DApp**。
当前迭代的实现与测试状态以 [进度记录](../../devlog/028-course-refactor.md) 为准；不要把设计目标当成已完成的验证。

## 建议阅读顺序

想先上手操作，请先看 **[第一次完整体验指南](EXPERIENCE_GUIDE.md)**：当前入口、MetaMask 测试账户、本地网络、到期退款，以及从新建赛事到领奖的逐步操作。

1. [需求与验收标准](REQUIREMENTS.md)：为什么做、服务谁、哪些内容属于本次作业。
2. [架构与设计决策](ARCHITECTURE.md)：链上与链下边界、状态机、资金与身份的信任模型。
3. [合约接口](CONTRACT.md)：合约职责、交易类型、权限与事件。
4. [后端 API](API.md)：配置、钱包登录、Agent 定义、赛事和证据查询。
5. [用户手册](USER_GUIDE.md)：按角色操作完整业务流程。
6. [运行与部署](DEPLOYMENT.md)：本地链、环境变量、云部署、持久存储与恢复。
7. [测试报告](TEST_REPORT.md)：已执行的检查、可复现命令、限制和待验收事项。
8. [学习路线](LEARNING_GUIDE.md)：代码阅读顺序、练习、答辩问题。
9. [报告与演示准备](SUBMISSION_PLAN.md)：10–15 页报告分配、图示、评价实验与十分钟演示脚本。

## 版本边界

- `specs/` 和早期 `devlog/` 保留黑客松阶段设计，部分结论已经过时。
- `docs/archive/HACKATHON_README.md` 保存本轮开始前的项目介绍，便于比较重构前后。
- 当前课程要求与本目录文档优先；旧文档中的“全链上”“已完成测试”“真实 USDC”等表述不能直接用于课程报告。
- 测试代币仅用于本地链或测试网；结果证据支持复核，不代表链上已经证明 LLM 的决策正确。
- 公网 URL、合约地址、用户访谈、实测性能和个人贡献只记录实际证据，不能填入虚构结果。
