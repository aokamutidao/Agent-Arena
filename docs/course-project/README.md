## 建议阅读顺序

想先上手操作，请先看 **[第一次完整体验指南](EXPERIENCE_GUIDE.md)**：当前入口、MetaMask 测试账户、本地网络、到期退款，以及从新建赛事到领奖的逐步操作。

界面导航为“资金概览 / 奖金赛事 / 审计流水 / 我的 Agent / 使用指南”。详情页先看“你的下一步”：它按本场身份和链时间给出操作。链上业务按钮会自动打开交易确认弹窗，核对后点“确认并在钱包签名”；关闭窗口不取消已发交易，待处理时可从底部入口恢复查看。

顶部 **English / 中文** 按钮切换整个课程界面；选择会保存在当前浏览器，刷新和页面跳转后仍生效。钱包连接弹窗、日期、角色和交易状态随之切换，用户内容和原始证据保留原文。

导航中的“使用指南”打开“怎么开始？”页面，提供按角色选择的上手入口；需要完整账户配置与实操教程时，继续阅读本目录的体验指南和用户手册。

2026-10-10 的体验指南与用户手册已同步新界面文案；其中余额快照均有日期，后续操作会变化。034 的 #7 MetaMask 主赛事已完成，已确认交易单独留档；取消退款、争议等分支没有在本轮钱包操作中验收。到期赛事会显示“已到期 · 待退款”，仍须先取消，再由赞助者领取退款。

## 版本边界

- `specs/` 和早期 `devlog/` 保留黑客松阶段设计，部分结论已经过时。
- `docs/archive/HACKATHON_README.md` 保存本轮开始前的项目介绍，便于比较重构前后。
- 当前课程要求与本目录文档优先；旧文档中的“全链上”“已完成测试”“真实 USDC”等表述不能直接用于课程报告。
- 测试代币仅用于本地链或测试网；结果证据支持复核，不代表链上已经证明 LLM 的决策正确。
- 公网 URL、合约地址、用户访谈、实测性能和个人贡献只记录实际证据，不能填入虚构结果。
