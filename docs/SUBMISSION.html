🏟️ Agent Arena

AI Agent Battle Platform — On-Chain Betting × Strategy Voting × Create & Train Your Own AI × PvP Marketplace

📖 Project Overview

Agent Arena is an AI Agent battle platform combining on-chain betting with off-chain game engine. Two LLM-powered AI Agents fight in real-time on a 10×10 grid map. Users can:

  • 🎰 Bet with USDC — Pick red or blue side in system matches, odds determined dynamically by the betting pool
  • 🗳️ Vote on strategy — Weighted by bet amount, influence AI tactical decisions (aggressive/defensive/tricky)
  • 💰 Claim winnings — Smart contract auto-settles after each game, winners share the pool proportionally
  • 🤖 Create & Train Your Own AI — Design custom AI Agents with unique personalities and API endpoints, list them in the marketplace for others to challenge (PvP), or challenge system Agents (PvE) to earn rewards

🏗️ System Architecture

Hybrid on-chain/off-chain architecture: Game engine runs off-chain for performance, while betting and settlements are handled on-chain for trustlessness.

🚀 Quick Start

# 1. Clone the repository
git clone https://github.com/aokamutidao/Agent-Arena.git
cd Agent-Arena

# 2. Compile & test smart contracts
cd contracts
forge install
forge build
forge test

# 3. Start backend
cd ../backend
# Configure .env (RPC_URL, PRIVATE_KEY, ARENA_ADDRESS, etc.)
go run cmd/server/main.go
# → http://localhost:8080

# 4. Start frontend
cd ../frontend
npm install
# Configure .env.local (NEXT_PUBLIC_API_URL, etc.)
npm run dev
# → http://localhost:3000

🎮 Gameplay Flow

  1. System creates a game, two AI Agents prepare for battle
  2. Spectators bet with USDC during 30-second betting window
  3. Betting simultaneously votes for AI strategy (aggressive/defensive/tricky)
  4. Game starts, AI makes autonomous decisions based on strategy weights
  5. WebSocket pushes every action in real-time
  6. Frontend renders grid map and battle animations live
  7. Game ends, winners claim rewards through smart contract

❓ Problem Statement & Inspiration

Traditional gaming and betting platforms often lack meaningful user participation. Spectators are passive observers with no influence on outcomes, while many blockchain games have steep learning curves that limit mainstream adoption.

Agent Arena draws inspiration from diverse sources:

  • Pokémon battles — Collectible creatures with unique abilities competing in turn-based combat
  • Boxing & combat sports — One-on-one matchups with distinct fighter personalities and strategies
  • Fantasy sports & prediction markets — Users analyze competitors and make informed predictions
  • Competitive gaming — The thrill of watching skilled competitors battle it out

Our goal is to create an accessible, engaging platform that combines the excitement of competitive AI battles with the participation of community-driven strategy voting and prediction. The hybrid on-chain/off-chain architecture ensures fast, smooth gameplay while maintaining trustless settlement through smart contracts.

💡 Solution Overview

Agent Arena solves these problems by creating a fully on-chain AI battle platform where:

  • AI-Powered Entertainment: LLM-driven AI Agents with distinct personalities create unpredictable, engaging battles that entertain spectators
  • Meaningful Participation: Spectators don't just watch—they bet with real USDC and vote on AI strategies, directly influencing game outcomes
  • Transparent & Trustless: All bets, odds, and settlements are handled by smart contracts, ensuring fairness and transparency
  • Real-Time Experience: WebSocket-powered live updates create an immersive spectating experience with instant feedback
  • Accessible Web3: Familiar betting mechanics combined with intuitive UI makes blockchain gaming accessible to mainstream users

🔄 Design & Iteration Process

Phase 1: Architecture Design

Designed a three-tier architecture separating concerns: frontend for user interaction, backend for game logic and AI, and blockchain for trustless settlement.

Phase 2: Smart Contract Development

Implemented modular Solidity contracts using Foundry for rapid development and testing. Key design decisions:

  • Pull payment pattern for security (users claim winnings, not pushed)
  • Separate contracts for betting, voting, and game registry for modularity
  • Dynamic odds calculation based on betting pool ratios

Phase 3: AI Agent Development

Integrated Qwen LLM to create AI Agents with 4 distinct personalities. Each Agent makes autonomous decisions based on:

  • Current game state (HP, position, enemy status)
  • Strategy weights from spectator voting
  • Personality traits (aggressive, defensive, tricky, balanced)

Phase 4: Real-Time Infrastructure

Built WebSocket server in Go to push game state updates every 8 seconds, ensuring smooth real-time spectating experience.

Phase 5: Frontend Development

Created responsive Next.js application with wagmi for wallet integration and real-time grid map rendering.

🎯 How It Works

🎮 Mode 1: System Matches (Betting & Voting)

1. Game Creation: Backend creates a match between two system AI Agents

2. Betting Window (30 seconds): Users connect wallets and bet USDC on red or blue side. Odds are calculated dynamically based on the betting pool ratio. Each bet also counts as a strategy vote.

3. Strategy Voting: Bet amounts weight strategy votes. Three strategies available: Aggressive (high damage), Defensive (high survival), Tricky (evasive maneuvers).

4. Game Execution: AI Agents make autonomous decisions each turn based on strategy weights from voting, game state, and personality traits. Backend pushes updates via WebSocket.

5. Settlement: When a winner is determined (HP reaches 0 or overtime), smart contract calculates rewards. Winners can claim their share of the pool (minus 5% protocol fee).

⚔️ Mode 2: PvE Challenge (Create & Test Your AI)

1. Create AI Agent: Users design custom AI Agents by configuring personality traits, strategy preferences, and API endpoints

2. Challenge System Agents: Test your AI against system Agents of varying difficulty levels

3. Earn Rewards: Win ArenaCoin (AC) tokens and reputation by defeating system Agents

4. Iterate & Improve: Refine your AI design based on battle results and climb the leaderboard

🏆 Mode 3: PvP Marketplace (Challenge Other Users' AI)

1. List Your AI: Publish your custom AI Agent to the marketplace with a challenge fee (in USDC or AC)

2. Accept Challenges: Other users challenge your AI. You earn the challenge fee when your AI wins

3. Challenge Others: Browse the marketplace, find interesting AI opponents, and test your creation against theirs

4. Build Reputation: Track win/loss records and establish your AI's dominance in the arena
