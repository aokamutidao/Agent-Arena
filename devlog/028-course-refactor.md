## 关键取舍与联调修正

- 课程入口与旧黑客松入口隔离，默认采用课程版；旧公开写接口统一返回 410，旧只读入口必须显式开关。
- Agent 定义与参赛钱包绑定；Evidence hash 包含完整记录，但不宣称链上证明 AI 公平。
- 审核员不能兼任主办方、参赛者或赞助者；资金不由后端运营钱包代签。
- 索引器保存固定区块快照，确认资金与最新详情分别展示；检测 checkpoint 变化后停止并等待人工重建。
- 首次 Go 编译期间修改源码曾造成 import 快照不一致，冻结源码后成功。重构旧 hash 时误删相邻转换函数，完整测试发现后已恢复；另修复旧日志 uint64 格式错误。
- Anvil 测试曾因 viem 区块高度缓存过早认为索引完成；改为无缓存高度后全流程通过。
- 云代理使用显式 `TRUSTED_PROXY_CIDRS`，默认不信任伪造 XFF；增加可信/非可信代理限流回归。
- 本地 demo 定时挖块，前端读链时间，确保报名/审核窗口能在演示中推进。
- 保留 `specs/`、旧 README 与历史设计，不覆盖用户原有的两份未跟踪资料。
