# S6 - 前端规格 (Frontend Specification)

## Agent Arena Frontend

---

## 1. 技术栈

```
框架:      Next.js 14 (App Router)
样式:      Tailwind CSS + shadcn/ui
状态管理:   Zustand (轻量级)
WebSocket: 原生 WebSocket API
钱包连接:   wagmi + viem + RainbowKit
动画:      Framer Motion (格子动画)
图表:      Recharts (赔率/收益图表)
图标:      Lucide React
```

**为什么选这些：**
- Next.js + shadcn/ui：组件丰富，AI（Claude）生成代码效果好
- Zustand：比 Redux 简单，适合小项目
- wagmi + RainbowKit：钱包连接标准方案
- Framer Motion：格子移动动画效果好

### 5.2 合约交互流程

```
下注流程：
1. 用户点击"确认下注"
2. 检查 USDC 余额
3. 如果未 approve → 弹出 approve 交易
4. approve 成功后 → 调用 betAndVote()
5. 等待交易确认
6. 更新本地状态

提取流程：
1. 用户点击"提取"
2. 调用 claim(gameId)
3. 等待确认
4. USDC 到账，更新余额
```

## 6. WebSocket 集成

```tsx
// hooks/useWebSocket.ts
export function useWebSocket(gameId: number) {
  const [gameState, setGameState] = useState<GameState | null>(null);
  const [turnHistory, setTurnHistory] = useState<TurnResult[]>([]);

  useEffect(() => {
    const ws = new WebSocket(`ws://localhost:8080/ws?game_id=${gameId}`);

    ws.onmessage = (event) => {
      const msg = JSON.parse(event.data);

      switch (msg.type) {
        case 'game_state':
          setGameState(msg.data);
          break;
        case 'turn_update':
          setTurnHistory(prev => [msg.data, ...prev].slice(0, 10));
          break;
        case 'betting_update':
          // 更新赔率显示
          break;
        case 'game_finished':
          // 显示结算弹窗
          break;
      }
    };

    return () => ws.close();
  }, [gameId]);

  return { gameState, turnHistory };
}
```

## 9. AI 辅助开发策略

由于前端经验有限，采用以下策略：

```
1. 使用 shadcn/ui 组件库（复制粘贴，不需要复杂配置）

2. 让 AI（Claude）生成组件代码：
   - 描述组件功能 + 设计稿（ASCII）
   - AI 生成完整组件代码
   - 手动调整样式细节

3. 优先完成核心流程：
   - 连接钱包 → 看到对局 → 下注 → 观战 → 提取
   - 其他功能逐步补充

4. 不做复杂的自定义动画：
   - Agent 移动用 CSS transition（简单）
   - 攻击效果用 Tailwind 的 animate-pulse
   - 不引入复杂的动画库
```
